# Scripts for removal of Cortex Cloud resources created with the Upgrade Helper tool for Prisma Cloud configurations
Removes the following:
 * Compliance Standards created from Prisma Cloud
 * Compliance Controls created from Prisma Cloud
 * Cloud Security Rules created from Prisma Cloud RQL Policies 
 * Workload Security Rules created from Prisma Cloud 
 * Vulnerability Rules created from Prisma Cloud 
 * Asset Groups created from Prisma Cloud 
 * Asset Groups Renaming (Stripping "Asset group for " prefix)
 * Correlation Rules Duplicates
 * Roles created from Prisma Cloud
 * Notification Rules created from Prisma Cloud
